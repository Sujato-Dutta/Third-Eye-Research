## Persistent verified self-updates

We study the value of parameter updates inside a recursive self-improvement
chain. At generation t, a language model M_t attempts problems from a fixed
training partition. Failed answers are followed by bounded correction attempts.
Only completions accepted by the task verifier enter the correction pool.
We construct three equal-sized candidate training batches from this pool.
Candidate compositions must differ, and examples are unique within each batch;
batches may overlap across candidates. Thus each branch receives the same
optimization budget while its verified training content varies.

Each candidate produces a persistently updated model M_t+1. We then apply one
standardized continuation procedure to that model to obtain M_t+2. Continuation
corrections can differ across branches because they are generated by different
updated models, but harvesting and optimization budgets are matched. If the
fixed harvesting budget supplies fewer than two verified corrections, the
continuation is terminal: M_t+2=M_t+1, with zero executed continuation optimizer
steps and an explicit availability indicator. We do not duplicate corrections
to force an update or alter branch budgets in response to scarcity.

Only the candidate's M_t+1 checkpoint can be committed to the recursive chain.
M_t+2 is a consequence label rather than a selectable update. Label collection
uses a predeclared random candidate policy over five generations, retaining a
history of accepted updates. These trajectories support analysis of local
two-step consequences along recursion; they do not demonstrate gains from an
online learned selection policy.

## Models, data and matched budgets

The study covers Qwen3-4B and Llama3.2-3B-Instruct on mathematical reasoning and
code generation, yielding four model/task streams. Updates use LoRA rank16,
alpha32, zero dropout, learning rate1e-4, fifty optimizer steps, microbatch size1,
gradient accumulation8 and maximum training length1024. Candidate batch size is2
for every branch. Feature extraction uses a ten-step probe and restores the
parent parameters before the actual update. Final configuration fingerprints,
backbone revisions and source manifests accompany the released artifacts.

The fixed harvesting portions contain1024 GSM8K training prompts for mathematics
and306 MBPP training prompts for code. Each failed problem permits eight correction
attempts under the frozen seed schedule. Training pools contain verified training
examples only. Candidate consequences are evaluated on64 target-development,
64 out-of-distribution-development and256 retention-development examples.
Retention uses the frozen multiple-choice conditional-likelihood procedure.
The code out-of-distribution set is the declared MBPP validation proxy; it does
not establish generalization to a separate code benchmark. Final manuscript
dataset tables must state the exact frozen manifests and all role definitions.

For consequence head j, the horizon-h label is the accuracy difference between
M_t+h and M_t on the same evaluation role. The scalar utility averages target,
out-of-distribution and retention differences with the frozen equal weights.
We retain all three physical heads as well as the scalar utility, allowing
improvements on one role to be distinguished from interference on another.

## Forecasting and independent confirmation

Forecasters receive only information available before commitment: allowed
state/candidate features, probe summaries and prior accepted-update history.
Post-update labels, branch checkpoints and future runtime fields cannot enter
their inputs. Training, development and held-out partitions separate whole
trajectories. The original Gate2 criterion and its failed decision are reported
without replacement by subsequent exploratory architectures or cohorts.

The balanced supplementary confirmation cohort contains seeds6142 and6143 in
each stream: eight new five-generation trajectories, potentially forty states
and120 candidate labels. All compared neural models, normalizations, ridge
coefficients, tree models and heuristics were frozen before any new outcome.
The primary comparison is the previously fixed Direct-H2 versus matched-H1
future-selection value. Other methods and horizon contrasts are supplementary;
the declared three diagnostic horizon contrasts use Holm correction. We perform
no fitting or model selection on this cohort and retain incomplete trajectories
in coverage reporting rather than replacing them.

## Reliability controls and selection value

The reliability supplement preselects generation0 of seed6142 and generation4
of seed6143 in every stream, giving one parent from each of eight independent
trajectories. It loads actual retained parent, M_t+1 and M_t+2 checkpoint weights
and verifies their stored hashes. Aligned reevaluations record prediction hashes,
verifier outcomes and differences from the original saved metric totals. Repeated
verification of identical code separates verifier variability from regeneration.
Historical branches whose weights were pruned are not silently reconstructed
and treated as their original models.

Each parent receives a fixed-candidate-batch optimizer-seed repeat, a
fixed-continuation-batch optimizer-seed repeat and two fresh continuation seeds
from the same saved M_t+1. All repeats retain the scientific budgets and terminal
rule. Original single-continuation labels remain unchanged; averages across
continuations are supplementary reliability estimates. Paired evaluation-item
resampling measures finite-item uncertainty conditional on fixed predictions.
Matched repeats measure sensitivity to the specified optimizer and continuation
changes, rather than a universal noise floor.

We report immediate-best, uniform-random and observed-future-oracle selections,
their future utility and selection regret. Holding parameters fixed over both
steps has zero utility by definition and is reported separately from forced
selection among updates. The observed oracle is privileged and susceptible to
finite-evaluation optimism. Fresh-cohort selection-value intervals resample whole
trajectories within streams and weight streams equally; forty states and120
labels are not120 independent units. Reliability estimates have eight independent
parents, with only two per stream and shared evaluation items limiting precision.

## Scope and reproducibility limits

Synthetic known-signal controls assess detection of a constructed forecastable
signal, not power for every possible real effect. Update-norm, retention-gradient,
diversity and NLL associations are descriptive mechanism analyses and do not
establish causality. Conclusions are limited to the tested backbones, LoRA
updates, two-step labels and five-generation random-policy trajectories. A
negative forecasting result does not imply intrinsic unpredictability or a
universal ceiling on recursive self-improvement.

All scientific execution uses scheduled Vista compute nodes. Artifacts record
source and configuration hashes, frozen method identities, correction provenance,
checkpoint identities, failures, terminal branches and coverage. Resource tables
must distinguish measured GPU node-hours, CPU allocations and charged service
units from reservation limits and planning estimates. The October11 experiment
