# Saved-data admission decision audit

Declared after reviewing the completed 16-parent B outcomes on October 21.
Every analysis here is exploratory. Preserve original B labels, fits, endpoints
and reports. This is the next CPU review, not confirmation or a new model.

Use only the fully fresh, fixed-rendering B cohort. Bind its plan, report,
completion, fits, accounting and submissions to hashes. Revalidate complete
candidate/continuation/item/checkpoint provenance on allocated CPUs and reproduce
the original H1/H2 fitted predictions, hyperparameters and admission actions
before interpreting new diagnostics. Never score or read sealed final outcomes.

Compare hold, forced immediate and protected replay with four transparent
constant-admission families: global, backbone, task and backbone/task stream.
Fit each context mean from training parents only, for both H1 and H2 labels.
Average each parent's immediate-selected candidate outcome when estimating the
context mean. Constants use threshold zero and the existing predicted-retention
floor. Context labels are explicit baseline inputs, not hidden predictor features.

Compare those baselines with the original four-feature ridge family and a
stream-offset residual ridge diagnostic. The latter centers features within
training streams and fits residual targets after a training-only stream mean;
it is a diagnostic of feature value beyond context, not a promoted controller.
Keep original ridge alphas, thresholds, retention floor and tie rules. No new
architecture, spectral features, label-horizon search or larger hyperparameter grid.

Use both original whole-parent CV (test parent, validation index+4 mod16, fourteen
training parents) and leave-one-seed-group-out sensitivity (four test parents,
next seed group for validation, eight training parents). Keep both hash-based
item orientations. Every fitting/validation target uses selection-half items;
scoring-half outcomes never determine coefficients or thresholds. No test-parent
future label enters a prediction. Average orientations/candidates within parents.

Report independently scored utility, retention, coverage, observed harmful
admissions/beneficial rejections, per-parent ranking correlations, prediction
error, feature extrapolation and residual-rule minus context-baseline effects.
Constant predictions have undefined rank correlation, not artificial zero skill.
Seed sensitivity has four groups; overlapping fits and seed folds are not extra N.

Quantify fixed-action parent-only, shared-item-only and directly crossed
parent/item uncertainty. Resample identical role/item-half pools together across
parents. Do not add/subtract conditional variances as identified components.
Use 1,000 crossed draws; fits, candidate selection and decisions remain fixed.

For planning sensitivity only, examine balanced N=16,48,64,96 and hypothetical
1x/2x/4x independent same-population item counts. Resampling the existing item
distribution does not create new data or prove unseen-item precision. Report
joint two-baseline superiority projections at 0.5/1/2pp using the original
conservative normal critical value. Retention/practical thresholds are separate.
No inference across new domains or refit uncertainty is covered by these curves.

Benchmark cost using all four observed runtimes per stream, 25% margin and
15-minute rounding. Compare the original 560-SU C envelope and project headroom.
Extra/sealed-item inference is unbenchmarked and must not be treated as free.
Available final-suite counts are metadata only: code OOD is a different benchmark
from development OOD, and historical item exposure remains unresolved. Do not
call any projected larger suite equivalent, affordable or untouched without audit.

Reserve at most 0.77 SU for full CPU validation (20min,0.11SU) followed by this
CPU audit (2h,0.66SU). Charge both to B development; B remains below its 192-SU
ceiling and the total ledger stays below 1,200. Submit scheduler requests only
through login resources; all verification, fitting and statistics use allocated
compute nodes. No GPU job, confirmation, recursion or scaling is authorized by
this audit's completion. Stop for a policy/precision/cost decision.
